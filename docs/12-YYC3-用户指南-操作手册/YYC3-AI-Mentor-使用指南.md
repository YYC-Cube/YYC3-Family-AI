## 一句话启动

```bash
cd /Volumes/Max/YYC3-Family-AI
./start.sh
```

脚本自动完成：环境检查 → Ollama 检测 → 模型拉取 → IDE 启动 → 浏览器打开

**之后每次只需要** `./start.sh`，10秒内进入 IDE。

## 技术架构

```
你 (浏览器) → Service Worker (离线缓存) → Ollama (本机推理)
                ↕                     ↕
           IndexedDB (本地存储)     qwen2.5-coder:7b (4GB模型)
```

全链路**零网络依赖**。本地推理、本地存储、本地运行。永不掉线。

## 入门建议

1. **第一次**：`./start.sh` — 脚本会拉取 ~4.5GB 模型（首次需下载）
2. **之后每次**：`./start.sh` — 10秒内进入 IDE
3. **想用云端**：左上角设置 → 模型 → 选择 Z.ai / OpenAI 兼容服务商
4. **想安装 PWA**：Chrome 地址栏 → 安装图标 → 像 App 一样用
